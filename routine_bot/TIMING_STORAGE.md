# 활성 풀이 시간과 저장 이전

## 개인 기록의 의미

활성 풀이 시간은 **도전 시작**을 누른 뒤 목표를 달성할 때까지 생각하기, 코드 편집, 실행 관찰, 실행 일시정지 중 검토에 쓴 시간이다. 실행기의 논리 턴 수와 별도 지표다. 앱 숨김, 명시적인 쉬기, 도움말·튜토리얼 열람, 다른 레벨에 머무는 시간은 제외한다. 여러 제외 사유가 겹치면 모두 해제되어야 누적이 재개된다. 예를 들어 도움말을 닫아도 앱이 숨겨져 있으면 시간을 세지 않는다.

실패, 처음 위치로 복원, 같은 도전의 재실행은 누적 시간·시도 수·힌트 표시를 지우지 않는다. 일반 실행 초기화와 별도로 **새 기록 도전**을 선택해야 새 기록을 시작한다. 쉬기 상태는 저장되므로 새로고침만으로 쉬기가 해제되지 않는다. 쉬기 동안 편집·실행을 잠그는 책임은 UI에 있고, 시간 모듈도 쉬기 중 실행 시도를 늘리지 않는다.

`timing.js`는 실행 중 `performance.now()`의 차이로 누적한다. `Date.now()`나 저장된 벽시계 시각은 계산하지 않는다. 기기 시계 변경으로 음수나 거대한 추가 시간이 생기지 않으며, 새로고침·닫았다 다시 열기에서는 저장된 누적값과 새 단조 시계 기준점으로 이어간다. 닫혀 있던 공백은 포함하지 않는다. 테스트용 시계가 뒤로 가거나 유효하지 않은 값을 반환해도 음수가 되거나 같은 구간을 중복 누적하지 않는다.

UI는 활성 도전의 스냅샷을 약 1초마다 저장하고 숨김, 페이지 종료, 레벨 전환, 도움말·쉬기 상태 변화에서도 저장한다. 콜백과 저장이 정상 동작하다 비정상 종료되면 마지막 주기 이후의 활성 시간 약 1초 미만을 잃을 수 있다. 브라우저가 콜백을 오래 중단하거나 저장을 차단하면 오차가 더 커질 수 있고, 저장 실패는 화면에 알려야 한다. 과거 시간은 벽시계로 추정해서 보충하지 않는다.

성공 기록은 `elapsedMs`, 저장 블록 수 `stored`, 논리 턴 수 `turns`, 실행 시도 수 `attempts`, 힌트·정답 도움 여부 `hintUsed`를 가진다. 도전 중 일반 도움말이나 규칙 예시를 본 경우도 보수적으로 **도움/예시 사용** 기록으로 구분한다. 같은 지도·규칙 버전의 최초 완료를 보존하고, 도움 없이 푼 기록과 도움받은 기록 각각의 최초·최고 시간을 나누어 저장한다. 최고 시간은 가장 짧은 활성 시간이며 저장 블록 수가 같아도 더 빠르면 갱신한다. 시간이 같으면 저장 블록 수, 그다음 턴 수로 동률을 가른다. 기존 `completed`의 최소 저장 블록 기록은 별도로 유지한다. 서버 검증 없는 이 브라우저의 개인 기록이며 경쟁 순위나 공정성이 검증된 기록으로 표시하지 않는다.

## 저장 형식

기존 키 `routinebot-save-v1`와 보조 키 `routinebot-save-v1-backup`을 유지한다. 내부 스키마 버전 1은 읽을 때 2로 이전한다.

```js
{
  version: 2,
  currentLevel: 12, // 기존 숫자 ID 또는 새 안정적인 문자열 ID
  completed: { /* 기존 true 또는 {stored, executed} 유지 */ },
  programs: { /* 기존 ID에 연결된 코드를 그대로 유지 */ },
  settings: { speed: 1, muted: true },
  unlocked: [1], // 이전에 얻은 접근 권한: 새 단계 삽입/순서 변경 시 유지
  records: {
    'coop-intro': {
      'map-1:rules-simultaneous-1': {
        first: { elapsedMs: 40000, stored: 2, turns: 2, attempts: 1, hintUsed: false },
        unassisted: { first: {/* 결과 */}, best: {/* 결과 */} },
        assisted: { first: {/* 결과 */}, best: {/* 결과 */} }
      }
    }
  },
  challenges: {
    'coop-intro': {
      versionKey: 'map-1:rules-simultaneous-1', elapsedMs: 12500, attempts: 2,
      hintUsed: false, started: true, finished: false, resting: false
    }
  },
  tutorialSeen: { 'box-intro': true }
}
```

지도 버전은 `level.version`, 규칙 버전은 `level.rulesVersion`으로 명시한다. `versionKey(level)`은 `map-${level.version || 1}:rules-${level.rulesVersion || '2'}`를 만든다. 지도·실행 조건을 바꿀 때 해당 버전을 올려야 한다. 서로 다른 버전의 최고 기록은 같은 그룹에 섞이지 않는다. 진행 중 도전의 버전이 바뀌면 그 새 조건에 맞는 도전을 새로 시작한다.

이전 1~15의 숫자 ID는 표시 위치와 무관하다. 레벨 목록의 순서로 다음 레벨을 구하며, 명시된 `prerequisites`가 있으면 그 조건을 사용하고 없으면 앞 단계 완료로 해금한다. 저장된 접근 권한과 완료된 레벨은 항상 접근 가능하다. 버전 1 이전에서는 기존 현재 레벨과 완료 기록으로 원래 접근할 수 있었던 숫자 레벨의 권한을 보존한다. 새 입문 레벨은 완료 처리하지 않으며, 그 레벨을 삽입했다고 기존 완료 레벨을 잠그지 않는다. 나중에 한도를 초과하게 된 옛 프로그램도 저장 구조가 유효하면 삭제하지 않고 편집 가능하게 남긴다.

시간 없는 기존 완료에는 `elapsedMs`를 생성하지 않는다. UI는 **기존 완료 · 시간 기록 없음**으로 표시한다. 다른 지도·규칙 버전의 시간만 있는 경우도 현재 버전 시간으로 가져오지 않는다.

저장 데이터는 신뢰하지 않는다. 명령 구조·깊이·개수, 안정적인 ID, 기록 시간·횟수·유형을 제한하고 알려진 필드만 복제한다. `__proto__`, `constructor`, `prototype` 키는 ID·버전으로 허용하지 않는다. 전체 저장은 256 KiB를 넘으면 쓰지 않는다. 깨진 주 저장은 보조 저장으로 복구하고, 특정 레벨 코드만 깨졌으면 정상 코드를 유지하며 해당 코드만 보조 저장에서 복구한다. 저장 거부·실패에도 메모리 상태로 플레이할 수 있다.

이 모듈 시험은 UI 잠금과 실제 브라우저 이벤트 연결의 증거가 아니다. 브라우저의 도전 시작·편집·재시도·쉬기·도움말·레벨 전환·새로고침 검증은 [최종 검증 보고서](COOP_VERIFICATION.md)에 기록한다. 실제 탭 숨김 1,200ms 제외, 복귀 누적 및 도움말 중첩도 독립 Chromium에서 확인했다.
