# 레벨 설계와 기준 프로그램

본편은 4챕터 12레벨이며, 본편을 마치면 13~15번 응용 도전이 열린다. 15개 레벨에는 총 18개 지도가 있다. **각 레벨의 저장 블록 상한은 그 레벨 기준 프로그램의 저장 노드 수와 같다.** 기준 프로그램은 가능성을 입증하는 제작자용 해답이며 최적해로 주장하지 않는다. 실제 게임은 이 문서나 `solutions.cjs`를 읽지 않고 `levels.js`에 기록한 상한만 사용한다.

표기: `앞`=앞으로, `왼`/`오`=제자리 회전, `반복 n[…]`=정해진 횟수 반복, `벽? 예[…] 아니요[…]`=앞이 막혔는지 검사, `별?`=현재 타일의 별 검사. `F1()`/`F2()`는 함수 호출이다. 비어 있는 분기는 `[]`이다. `길읽기`는 문서에서만 쓰는 약칭으로, 게임의 새로운 명령은 아니다.

`길읽기 = 벽? 예[오] 아니요[별? 예[왼] 아니요[], 앞]`

지도는 `levels.js`에서 행 문자열과 시작 좌표로 정의한다. 별은 색과 별 모양을 함께 사용한다. 8·9·13·15번의 별 너머에는 짧은 막다른 길이 있어 별이 없는 벽 추종과 다른 판단이 필요하다. 12·15번의 각 지도는 처음 상태부터 별도로 실행하며 이전 지도 위치나 실행 상태를 이어받지 않는다.

저장 상한은 선택 배지 목표가 아니라 실행에 필요한 제한이다. 시작·F1·F2의 모든 저장 노드를 합하며, 반복·조건 상자 자체와 양쪽 분기도 센다. 이동·회전 등 종류별 사용 개수를 따로 제한하지 않는다. 상한 이하에서 해결하는 다른 프로그램도 허용하므로 기준 프로그램과 구조가 같거나 블록 수가 정확히 같을 필요는 없다. 예를 들어 4번은 상한 2개 안에서 반복과 이동을 조합해야 하며, 앞으로 다섯 개를 나열하는 프로그램은 실행할 수 없다. 실제 실행 횟수는 별도의 한도를 사용한다.

도착 즉시 끝나는 규칙 때문에 기준 프로그램의 마지막 회전이나 남은 반복은 실행되지 않을 수 있다. 예를 들어 5번은 마지막 계단의 앞으로에서 도착하고 마지막 왼쪽 회전을 생략한다. 11번은 F1 안에서 도착하므로 남은 함수 복귀가 없다.

## 검증과 증거

```sh
node --test routine_bot/engine.test.cjs
node --test --test-name-pattern="reference level [123]:|coordinates|turns|wall collision|early collision" routine_bot/engine.test.cjs
```

첫 명령은 손으로 예상한 독립 엔진 시험과 15개 레벨의 모든 지도를 검사한다. 저장 상한은 별도로 손으로 센 고정 수열 `3, 5, 6, 2, 5, 7, 4, 4, 6, 11, 9, 6, 9, 10, 9`와 비교하고, 각 기준 프로그램의 저장 수가 상한과 정확히 같은지 검사한다. 기준 프로그램 뒤에 블록 한 개를 더한 프로그램은 집 뒤의 실행되지 않는 명령이라도 시작 전에 거부되는지 확인한다. 같은 기준 프로그램으로 18개 지도 모두의 해결 가능성을 계속 검사한다. 두 번째 명령은 초반 3레벨 적용 시점에 쓰는 작은 재현 집합이다. 해답 실행은 프로그램 편집 UI의 사용성 검사가 아니다. 실제 블록 추가·수정·실행으로 하는 탐색 플레이와 기록을 구분한다. 실행 로그와 화면 증거의 위치는 [README.md](README.md)의 검증 절차를 따른다.

## 기록한 가역적 결정

- 요구에 있는 “12레벨·4챕터”를 본편으로, 13~15번을 본편 이후 응용 3레벨로 해석했다.
- 본편 1~3에서는 반복·조건·함수 블록을 숨긴다. 4부터 반복, 7부터 벽 조건, 8부터 별 조건, 10부터 F1, 11부터 F2를 연다.
- 임의 프로그램 문자열, 온라인 계정, 순환 호출, 자유 지도 제작은 포함하지 않았다.
- 벽 조건은 앞 타일, 별 조건은 현재 타일을 읽는다. 별 판정 후 이동을 공통 명령으로 둘 수 있어 조건 안쪽 편집 부담을 줄였다.
- 2026-10-19 사용자 요청에 따라 각 기준 프로그램의 전체 저장 노드 수를 필수 상한으로 정했다. 종류별 할당은 두지 않으며, 최소·최적 블록 수를 증명한 값으로 표현하지 않는다. 기존 선택 도전 기준은 제거했다.
- 함수 복귀는 읽을 수 있는 화면 이벤트를 유지하면서 실행 횟수에서는 제외했다. 저장 수와 실행 수의 정의는 [RULES.md](RULES.md)에 고정했다.
