루틴봇 게임 방법

작은 로봇에게 순서대로 할 일을 건네고 집까지 보내 주세요. 예상과 다르게 움직여도 괜찮아요. 방금 움직인 명령을 찾아 조금 고치면 다음 시도가 됩니다.

먼저 한 번 보내 보기

  1. 지도에서 로봇의 화살표와 집을 찾아보세요. 화살표는 앞으로 움직일 방향입니다.
  2. 도전 시작을 누르면 생각·편집부터 시간을 기록해요. 먼저 편집했다면 도전 시작 · 실행으로 측정을 시작할 수도 있어요.
  3. 앞으로 블록을 눌러 명령에 넣으세요. 회전은 같은 자리에서 방향만 바꿉니다.
  4. 표시된 블록 제한 안에서 실행을 누르고 지도와 빛나는 명령을 함께 보세요. 집에 닿으면 그 지도는 성공입니다.
  5. 길이 다르면 명령을 선택해 고치고 다시 실행하세요. 초기 위치로 돌아가도 작성한 명령은 남습니다.

설명을 모두 읽을 필요는 없어요. 새 기능은 필요한 레벨에서 하나씩 열립니다. 막히면 힌트를 한 단계씩 확인하세요. 첫 힌트는 지도의 어느 부분을 볼지 알려줍니다.

상자 배송과 함께 귀가하기

앞으로 갈 때 바로 앞에 상자 하나가 있고 그 뒤 칸이 비어 있으면 한 칸 밀어요. 미는 방향으로 두 상자가 이어지면 밀 수 없어요. 옆으로 나란히 붙은 상자는 괜찮습니다. 벽·지도 밖·다른 로봇으로 막힌 칸에도 밀 수 없어요. 당기기, 연쇄 밀기, 힘 합치기는 제공하지 않아요.

▣ 점선 테두리는 상자 목적지예요. 상자는 서로 바꾸어 놓아도 됩니다. A ○는 A ○ 집으로, B ◇는 B ◇ 집으로 돌아가요. 집과 상자 목적지는 다른 칸이고, 로봇이나 상자가 올라가도 테두리와 표식이 남아요.

목적지를 모두 상자로 채우고 로봇이 모두 자기 집에 있는 순간에 성공해요. 먼저 귀가한 로봇은 계속 움직일 수 있고, 배송한 상자도 다시 밀 수 있어요.

코드는 하나, 판단은 각자

협동에서는 하나의 공통 프로그램을 사용해요. 로봇마다 명령 위치, 반복 횟수, 함수 호출은 따로 진행됩니다. 앞에 상자?, 내 집 위?, 별·막힘 조건도 각자의 위치와 방향에서 판단해요. A/B 번호로 분기하는 명령은 없습니다.

앞이 막힘?은 지금 밀 수 있는 상자를 막힘으로 보지 않아요. 다른 로봇이 이번 턴에 어디로 갈지는 미리 알지 못합니다. 로봇 선택 버튼으로 해당 로봇의 실행 명령과 막힌 이유를 살펴보세요. 성공한 밀기는 초록 ↑, 실패한 밀기는 빨강 ×로 표시해요.

한 턴은 함께 움직이는 한 박자

턴 시작 상태에서 각 로봇이 다음 이동·회전·기다리기 하나를 고르고, 충돌을 함께 판정한 뒤 가능한 행동을 동시에 적용해요. 조건·반복·함수 진입·복귀 자체는 시간을 보내지 않아요. 위험을 먼저 확인하고, 안전할 때만 성공을 판정합니다.

  • 같은 칸으로 가려는 움직임과 같은 상자를 미는 움직임은 모두 취소해요.
  • 자리 맞교환은 안 돼요. 턴 시작에 다른 로봇이 있던 칸은 이번 턴에 비워져도 못 들어가요.
  • 다른 상자가 이번 턴에 움직여도 두 상자를 연쇄로 밀 수 없어요. 밀기는 로봇과 상자가 함께 성공하거나 함께 취소돼요.
  • 막힌 행동도 한 턴을 쓰고 다음 명령으로 넘어가요. 관계없는 로봇의 행동은 그대로 실행해요.

명령이 끝난 로봇은 제자리에 남고 다른 로봇은 계속해요. 모두 끝났는데 배송·귀가가 남으면 미완료로 안내해요. 기존 단일 로봇 지도는 벽 충돌 즉시 실패, 집 도착 즉시 성공 규칙을 유지합니다. 상자 도입 지도는 한 대여도 새 동시 턴 규칙으로 연습해요.

게임의 짧은 튜토리얼에는 한 화면에 규칙 하나와 직접 한 턴씩 움직이는 예시가 있어요. 건너뛰기·다시 보기가 가능하고, 연습 버튼은 해당 실제 도입 스테이지로 이어져요. 같은 레벨을 튜토리얼 때문에 두 번 완료할 필요는 없습니다. 예시 열람도 도움 받은 기록으로 구분합니다.

누르고 고치는 명령 블록

마우스나 손가락으로 블록을 추가하고, 이미 놓인 블록을 선택해 이동하거나 삭제할 수 있습니다. 드래그가 없어도 모든 명령을 편집할 수 있어요. 잘못 바꿨다면 실행 취소로 이전 편집을 되돌리세요.

반복과 조건의 명령은 부모 블록 아래에 가지처럼 펼쳐져 앞뒤 코드를 함께 볼 수 있습니다. 펼치기 / 접기로 표시할 부분을 고르고, 가지의 ＋ 추가 버튼으로 새 블록을 넣을 곳을 선택하세요. 반복 횟수는 해당 반복 카드에서 바꿉니다. 현재 편집 중인 가지를 접으면 추가 위치가 부모 쪽으로 돌아가며, 작성한 명령은 그대로 남습니다. 현재 편집 범위와 선택된 가지 표시로 다음 명령이 어디에 들어갈지 확인할 수 있습니다. F1·F2는 보관함 탭에서 편집합니다.

키보드는 Tab으로 버튼을 옮기고 Enter 또는 Space로 누를 수 있습니다. 입력칸 밖에서는 Ctrl/Cmd+Enter로 실행·멈춤, R로 처음 위치, Ctrl/Cmd+Z로 실행 취소, F로 전체화면을 사용할 수 있습니다. 버튼·링크 밖에서는 Space로도 실행·멈춤을 할 수 있습니다.

움직임을 천천히 살펴보기

  • 실행 / 멈춤: 이어서 움직이거나 잠시 멈춥니다.
  • 한 단계: 다음 명령 하나의 판단이나 움직임을 살펴봅니다.
  • 처음 위치: 로봇만 출발 위치로 돌립니다. 명령은 유지됩니다.
  • 코드 비우기: 작성한 명령을 비웁니다. 위치 초기화와 별도 동작입니다.
  • 속도: 처음 보는 명령은 느리게, 익숙한 명령은 빠르게 확인하세요.

벽에 부딪히면 그 칸과 실행 중이던 명령이 강조됩니다. 명령이 끝났는데 집에 닿지 않았다면 방향과 이동 횟수를 다시 보세요. 실패해도 프로그램은 사라지지 않습니다.

한 박자 쉬고, 깜빡이는 길 건너기

5레벨부터 한 박자 기다리기가 열립니다. 앞으로·좌회전·우회전·기다리기는 각각 시간을 한 칸 진행시켜요. 반복이나 조건을 읽고 함수를 부르는 동안에는 시간이 흐르지 않습니다.

위험칸의 ×는 지금 위험, !는 다음 행동 뒤 위험을 뜻합니다. 시간표를 펼쳐 앞으로의 박자를 확인할 수 있어요. 이동이나 회전·기다리기가 끝났을 때 켜진 칸에 있으면 실패합니다. 안전할 때 들어가도 그 칸에서 오래 머물면 위험해질 수 있어요.

화면을 오래 보고 있거나 속도를 바꿔도 위험 박자는 달라지지 않아요. 코드의 기다리기로 출발과 움직임의 박자를 조절하세요. 처음 위치로 돌아오거나 다음 지도를 시작하면 시간은 다시 0입니다. 앞이 벽인지 묻는 조건은 위험칸을 벽으로 보지 않으므로, 길 모양과 위험 시간표를 함께 살펴보세요.

기존 길 사이에 이어지는 새 도전

  1. 1–3 · 순서: 앞으로, 좌회전, 우회전으로 방향과 명령의 순서를 익힙니다.
  2. 4–6 · 반복: 같은 움직임을 묶어 반복하고, 기다리기로 위험 계단의 박자를 맞춥니다.
  3. 7–9 · 조건: 앞이 막혔는지, 지금 선 칸에 표식이 있는지에 따라 다른 명령을 실행합니다. 표식에서 쉴 때도 골라 보세요.
  4. 10–12 · 함수: F1·F2에 이름 붙인 움직임을 보관하고 불러옵니다. 여러 지도에서 같은 프로그램이 통하는지도 도전합니다.

위 숫자는 기존 레벨 ID예요. 표시 순서는 새 도전을 포함한 여정 순서입니다. 첫 회전 연습 뒤 상자, 계단 뒤 대기, 조건 뒤 서로 다른 두 지도, 함수 뒤 재사용 도전, 여러 지도 뒤 협동과 배송을 만나요. 마지막은 위험 박자와 협동을 결합합니다. 기존 완료한 길과 코드는 보존돼요.

각 레벨은 표시된 블록 제한을 지켜요. 대기 전용 연습은 앞으로·기다리기, 함수 재사용 연습은 이동·회전·F1만 사용합니다. 도구 범위는 안내와 팔레트에 공개돼요. 기존 모든 레벨에서 기준해답의 기능이 꼭 필요한 것은 아닙니다. 예를 들어 기존 12레벨은 함수 없이 풀어도 됩니다.

명령 수와 위험 시간

저장한 명령 수는 프로그램에 놓인 블록의 수입니다. 반복 안쪽과 조건의 두 갈래, 함수 안쪽도 포함합니다. 실행한 명령 수는 로봇이 실행 중에 실제로 처리한 횟수입니다. 같은 블록을 반복하거나 함수를 여러 번 부르면 실행 횟수가 늘어납니다.

위험칸 옆의 시간은 이동·회전·기다리기만 셉니다. 예를 들어 반복을 읽으면 실행 수는 늘지만 위험 시간은 그대로예요. 세 숫자는 서로 다른 정보를 알려줍니다.

코드 옆의 저장한 수 / 블록 제한을 확인하세요. 제한을 넘는 블록은 추가할 수 없고, 초과한 코드는 실행할 수 없습니다. 반복 횟수를 늘려도 저장 블록 수는 늘지 않습니다. 실행 횟수와 중첩에는 별도의 안전 제한이 있습니다.

이전 버전에서 저장한 코드가 새 제한보다 길어도 지우지 않습니다. 초과 안내를 보며 블록을 하나씩 삭제하거나 실행 취소로 되돌릴 수 있어요. 중간 수정도 저장되며, 제한 안으로 줄인 뒤 다시 실행할 수 있습니다.

이어 하기와 화면 설정

활성 풀이 시간은 실제로 생각·편집·실행을 관찰한 시간이에요. 실행을 멈추고 검토하는 시간도 포함합니다. 실패·처음 위치·재실행으로 초기화되지 않고 레벨 이동이나 새로고침 후에도 이어집니다. 쉬기는 편집과 실행을 잠그고 시간을 제외해요. 앱이 숨겨진 시간과 도움말·튜토리얼 시간도 제외합니다. 도움말은 실행 상태를 보존하며 멈추고, 닫은 뒤 실행 버튼으로 직접 이어가요.

성공하면 풀이 시간·실행 턴·저장 블록·시도 수·도움 여부를 보여줘요. 새 기록 도전은 시간·시도·도움 표시를 새로 시작하는 별도 버튼입니다. 완료 후 일반 재실행은 연습이에요. 최초 기록과 가장 빠른 개인 기록은 따로 남고, 도움받은 기록과 다른 지도·규칙 버전 기록은 섞지 않아요. 옛 기록에 시간이 없으면 기존 완료 · 시간 기록 없음으로 표시합니다.

기기 시계 변경과 무관한 단조 증가 시계로 누적하고 약 1초마다 저장해요. 비정상 종료 시 마지막 저장 뒤 약 1초 미만을 잃을 수 있으며, 브라우저 중단·저장 실패 때는 오차가 커질 수 있어요. 서버 검증 없는 개인 기록으로, 공정성을 검증한 경쟁 기록이 아닙니다.

진행 상황과 레벨별 프로그램은 이 브라우저에 자동 저장됩니다. 같은 기기·브라우저·사이트 주소로 돌아오면 이어할 수 있습니다. 저장 공간이 차거나 사용할 수 없으면 안내를 표시하고 현재 게임은 계속할 수 있습니다. 그때는 창을 닫은 뒤의 복원을 보장할 수 없습니다. 브라우저 데이터 삭제, 비공개 창 종료, 다른 기기로의 이동은 저장을 공유하지 않습니다.

게임은 외부 로그인이나 온라인 순위 없이 동작하며 모든 게임 자산은 저장소에 포함되어 있습니다. 처음 페이지를 불러오려면 사이트 또는 로컬 정적 서버에 접근해야 합니다. 별도의 오프라인 설치 기능은 제공하지 않습니다.

표식은 색과 모양을 함께 사용합니다. 기기의 동작 줄이기 설정을 존중하고, 좁은 화면에서는 지도를 보며 명령을 탭으로 편집할 수 있습니다. 소리를 켰다면 음소거 버튼으로 끌 수 있습니다.

제작 원리와 상세 기능

명령을 읽는 규칙

로봇은 상하좌우 네 방향 중 하나를 봅니다. 앞으로는 현재 방향으로 한 칸, 회전은 제자리에서 90도입니다. 지도 바깥과 벽으로는 이동할 수 없습니다. 조건은 그 블록을 만났을 때의 로봇 위치와 방향으로 판단합니다. 반복은 정해진 횟수만큼 안쪽 명령을 순서대로 실행합니다.

함수를 호출하면 해당 함수로 들어가고, 끝나면 불렀던 지점의 다음 명령으로 돌아옵니다. 자기 자신을 다시 부르거나 F1과 F2가 서로를 계속 부르는 재귀·순환 호출은 허용하지 않습니다. 기존 단일 로봇은 안전한 집에 도착하면 즉시 종료하고, 협동은 전체 배송·귀가가 동시에 끝나야 종료합니다. 위험 실패가 성공보다 우선합니다. 여러 지도는 같은 프로그램으로 모두 통과해야 성공합니다.

명령은 구조화된 블록 데이터로 해석하며 사용자 문자열을 JavaScript로 실행하지 않습니다. 구체적인 실행 규칙·제한, 시험 명령, 검증 범위는 개발 및 검증 안내를 참고하세요. 플레이 평가 기록은 브라우저 자동화 관찰과 실제 사용자 반응을 구분합니다.

독자적인 작은 귀갓길

명령을 조합해 움직임을 관찰하는 직관적인 퍼즐 형식에서 영감을 얻었습니다. 이 게임의 이름, 루틴봇 캐릭터, 지도, 그림, 문구는 WebSim을 위해 새로 만들었습니다.
