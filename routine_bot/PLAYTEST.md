# 루틴봇 렌더링 플레이 평가

## 범위와 방법

2026-10-18, 구현 담당과 별도의 검토 에이전트가 `.agents/skills/game-playtest/SKILL.md`를 직접 읽고 절차를 실행했다. 현재 세션의 자동 등록 목록에 새 스킬이 추가되었다고 주장하지 않는다. Chromium 145.0.7632.6의 실제 DOM 버튼을 마우스 클릭·키보드·터치로 조작했다. 지도는 캡처, 접근성 트리와 읽기 전용 `render_game_to_text()`로 관찰했다. `solutions.cjs`, `LEVELS.md`, 기준 해답 시험은 읽지 않았으며 프로그램·성공 상태·진행 상황 주입 없이 새 저장에서 시작했다.

이는 브라우저 자동화와 에이전트의 독립 탐색 관찰이다. 실제 사람의 재미·이해·만족도는 미확인이다. 실제 Android 기기: **NOT RUN**.

증거: `output/playwright/routine-bot/blind/actions.ndjson`에는 입력·화면 접근성 트리·읽기 전용 상태·오류가 시간순으로 남는다. 같은 폴더의 개별 JSON과 PNG는 각 조작 직후 증거다. `session.cjs`는 실제 조작만 허용하는 독립 탐색 세션 도구이며 `node output/playwright/routine-bot/blind/session.cjs` 실행 뒤 JSON 줄로 `goto`, `click`, `tap`, `select`, `press`, `observe`를 전달한다. 산출물 폴더는 저장소에서 제외되므로 고정 재현 절차는 프로젝트 스킬과 정식 `tests/routine-bot.browser.cjs`를 사용한다.

## 초기 1–3레벨 적용

- **PASS — 데스크톱 1440×900, 마우스·키보드:** 첫 화면에서 집, 로봇 방향, 첫 버튼을 식별했다. 레벨1을 앞으로 3개·실행으로 해결하고 다음 길로 이동했다. 레벨2에서 앞으로 3개로 의도적인 충돌을 만든 뒤 세 번째 블록 삭제, Ctrl+Z 복구, 다시 삭제와 회전·이동 추가로 해결했다. 레벨3을 지도에서 추론해 해결했다.
- **PASS — 편집·실행 관찰:** 레벨3 회전 블록을 선택해 뒤로 이동하고 앞으로 되돌렸다. 속도 0.5× 실행→멈춤에서 위치가 고정되고 한 단계로 회전만 진행했다. 처음 위치로 되돌리자 작성한 6개 블록을 유지했다. 4×로 재실행해 성공했고 새로고침 후 1–3 완료·다음 레벨 열림·프로그램이 복원됐다.
- **PASS — 좁은 세로 320×740, 터치 에뮬레이션:** 별도 새 저장에서 레벨1–3을 실제 탭으로 해결했다. 레벨2의 회전 블록 선택→이동→삭제→실행 취소 두 번으로 올바른 프로그램을 회복했다. 스크롤 중에도 지도와 핵심 실행 버튼이 고정되어 탭으로 재실행할 수 있었다. 콘솔·페이지 오류 0건.
- **시각 판단:** 데스크톱 지도와 로봇이 화면의 중심이고 편집기가 옆에 놓인다. 집과 방향 화살표는 문장을 읽기 전에 구별 가능했다. 명령 강조와 충돌 칸의 X를 함께 확인할 수 있다. 긴 설명을 펼칠 필요가 없었다. 모바일의 25px 전후 지도 타일은 직접 누르는 대상이 아니며 명령 버튼은 별도 충분한 탭 영역을 갖췄다.

### 관찰 → 문제 → 수정 → 같은 장면 재시험

1. **레벨2, 충돌 안내 문구:** `early-l2-wall.png`에서 벽 위치 X와 세 번째 블록을 정확히 강조했다. 다만 문구가 “방향을 바꾸거나 조건을 확인”이라고 해 아직 열리지 않은 조건 기능을 언급했다. 초반에는 방향·이동 횟수를 안내하도록 구현 담당에게 수정 요청했다. 수정 후 같은 F,F,F 충돌 장면을 다시 확인할 예정이다.
2. **레벨2, 실패 후 수정:** 충돌 뒤 작성한 3개 블록이 그대로 남았고 선택·삭제·Ctrl+Z·재편집으로 성공했다. `early-l2-wall.png` → `early-l2-undo.json` → `early-l2-win.png`. 수정이 필요할 정도의 지연·데이터 손실은 관찰되지 않았다.
3. **320×740, 편집 영역 스크롤:** 고정 지도 아래에서 선택 블록의 이동·삭제·실행 취소가 실제 탭으로 동작했다. `early-narrow-l2-selected.png`, `early-narrow-l2-reorder.json`, `early-narrow-l2-undo-reorder.json`, `early-narrow-l2-win.png`. 전체 페이지 캡처는 sticky 요소가 현재 스크롤 위치에 찍혀 빈 자리처럼 보일 수 있으므로 실제 입력 성공 기록과 함께 읽는다.
