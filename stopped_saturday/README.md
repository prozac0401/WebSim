# 멈춘 토요일 · Saturday, Interrupted

발목 부상으로 움직임과 시간의 감각이 달라진 토요일을 다루는 선택형 이야기입니다. 사용자가 제공한 `멈춘토요일_v0.1_소스.zip`의 `stopped_saturday_0_1/index.html`을 분석해 통합했습니다. 원본의 네 출발 경로, 다섯 번의 선택, 여섯 결말 이름과 “시간은 남아돈다. 발목은 남아돌지 않는다.”를 보존합니다.

이번 확장은 구체적인 생활 장면과 누적되는 몸의 반응, 실제 이동을 보여 주는 삽화를 추가합니다. 게임의 기초 구조를 유지하면서 선택 뒤의 경험을 늘렸습니다.

생활 장면에는 네이버 지도로 입구와 동선을 확인하는 일, 배민의 배달·픽업과 버거킹의 멤버십·쿠폰 조건을 비교하는 점심, 오를 수는 있어도 곡예처럼 느껴지는 2층 계단을 담습니다. 작은 동작에 맞춰 남은 여유를 보여 주는 상상 속 에너지 모니터로 짧은 이동의 부담도 표현합니다.

## 실행

저장소 루트에서 정적 서버를 실행합니다.

```sh
python -m http.server 8000
```

`http://localhost:8000/stopped_saturday/stopped_saturday.html`을 엽니다. 설치·빌드·외부 CDN·로그인·서버 API 없이 실행하며 GitHub Pages 정적 경로를 사용합니다. 설명서는 `stopped_saturday_doc.html`입니다. 파일을 직접 열어도 게임을 진행할 수 있지만 클립보드 등 브라우저 기능은 실행 환경의 제약을 받습니다.

## 설계

- 시작은 10:12이며 다섯 번의 이야기 선택 후 저녁 결말에 도달합니다. 선택 후 반응을 읽고 넘기는 동작은 추가 선택으로 세지 않습니다.
- 에너지·마음의 온도와 행동의 흔적을 유지합니다. 낮은 에너지는 패배나 선택 잠금으로 이어지지 않습니다.
- 발목, 어깨, 등, 겨드랑이, 손바닥, 반대쪽 다리의 상태를 함께 기록합니다. 누적되는 이동 부담, 같은 자세의 뻐근함, 쉬거나 동선을 바꾼 뒤의 부분적인 완화를 문장과 동작에 연결합니다. 이 값은 임상 척도나 신체 시뮬레이션이 아닙니다.
- 여섯 결말은 몰입·연결·이동·쉼·관찰·창작의 흔적을 반영합니다. 특정 행동 한 번이 나머지 하루를 무조건 덮어쓰지 않도록 판정합니다. 좋은 결말·실패 결말 구분은 없습니다.
- 목발 이동은 손잡이로 지지하는 삽화이며 겨드랑이에 체중을 매다는 동작을 올바른 보행으로 제시하지 않습니다. 무리한 이동·운전, 의지에 의한 부상 극복을 권하지 않습니다.
- 움직임은 선택 뒤의 유한한 장면입니다. 애니메이션 시간은 상태 변화나 결말에 영향을 주지 않습니다. OS의 움직임 줄이기와 화면 설정을 존중합니다.
- 동작별 모니터는 이야기의 상태 변화를 시각적으로 나눈 표시입니다. 실제 칼로리·대사량을 측정하지 않으며, 애니메이션 재생으로 상태를 반복 차감하지 않습니다. 2층 계단은 일상의 집중·상체 부담·도착 후 피로를 표현하고 보행 기술이나 묘기 순서를 안내하지 않습니다.
- 실제 서비스의 기능·기간 한정 행사와 가상 인물의 경험을 구분합니다. “이날 이 주문에서 적용되지 않는 혜택”을 이야기하며, 배달이 항상 비싸거나 쿠폰이 적다고 일반화하지 않습니다. 사용자의 실제 회원 등급·주소·쿠폰을 읽거나 주문하지 않습니다.
- 선택·결과는 서버로 전송하지 않습니다. PNG·문구 복사·브라우저 공유는 사용자가 요청할 때만 실행합니다. 로컬 주소나 배포가 확인되지 않은 링크를 공유 문구에 넣지 않습니다.

## 검증

저장소 루트에서 실행합니다.

```sh
node --test stopped_saturday/story-engine.test.cjs tests/stopped-saturday-catalog.test.cjs
```

엔진 검사는 모든 완주 경로의 다섯 선택·상태 범위·여섯 결말 도달, 초기화, 누적 반응과 선택 이력의 반영을 확인합니다. 카탈로그 검사는 실제 카드 수와 안내 문구, 신규 분류·검색어, 기존 실행 및 사용법 경로를 확인합니다. 카탈로그 경로 검사는 기존 시뮬레이터 내부의 모든 동작을 보장하지 않습니다.

Playwright와 Chromium이 있는 환경에서 정적 서버를 켠 뒤 다음을 실행합니다.

```sh
node tests/stopped-saturday.browser.cjs
```

브라우저 검증 결과와 화면 캡처는 루트 작업 기록의 실제 실행 결과를 확인하세요. 실행하지 않은 브라우저·보조공학 환경은 통과로 간주하지 않습니다. 수동 확인 항목은 스크린리더의 실제 발음·탐색, iOS/Android의 시스템 공유 메뉴와 다운로드 동작, 실제 사용자의 부상 경험에 대한 문구 피드백입니다.

브랜드 로고나 앱 화면을 복제하지 않으며 별도 API·로그인·결제 연동은 없습니다. 이야기의 가격 비교와 감정은 창작 장면이고, 특정 계정의 실제 혜택 검증이나 현재 할인 추천 서비스가 아닙니다.

### 2026-10-24 생활 장면 확장 후 실행 결과

- 신규 엔진24개·카탈로그4개·기존 회귀10개, 총 **38/38 자동 검사 통과**. 36개 선택, 전체1024개 완주 경로와 여섯 결말 도달을 확인했습니다.
- 실제 Chromium **20개 검사 묶음 통과**. 키보드·터치·재시작·움직임 줄이기·목적지 착석·카탈로그 검색과 이동·클립보드 복사·1080×1350 PNG 다운로드를 확인했습니다. 320/360/390/768px과 데스크톱 화면에서 가로 넘침을 검사하고 캡처를 직접 확인했습니다.
- 계단을 올라 2층 벤치에 앉기, 엘리베이터·1층 픽업·귀가 후 배달 대안, 상상 속 에너지 모니터의 시작/종료 값과 시간에 따른 중복 차감 방지를 검사했습니다. 320px 터치 화면과 움직임 줄이기에서도 계단과 모니터를 확인했습니다.
- 브라우저 공유 API 분기는 모의 API로 검증했습니다. 실제 운영체제 공유창·스크린리더 발화·실물 모바일 기기·기존 모든 시뮬레이터의 전체 내부 동작은 미검증입니다.
- 원본 develop-web-game 클라이언트의 시작·선택·이동·배터리 표시 검사도 실행했습니다. 이번 증거는 저장소의 무시된 `output/playwright/stopped-saturday-everyday/`, `output/playwright/saturday-everyday-client/`에 있습니다. 초기 통합 증거는 `output/playwright/stopped-saturday/`, `output/playwright/saturday-client/`에 보관합니다.
