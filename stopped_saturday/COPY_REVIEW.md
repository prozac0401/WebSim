# 《멈춘 토요일》 한국어 문체 통합 검토

2026-10-25 · 통합 기준 main: `5a8a98a` (PR #119의 다친 쪽 무작위 선택까지 포함)

통합 대상은 [PR #116](https://github.com/prozac0401/WebSim/pull/116)의 `e157dae`와 [PR #117](https://github.com/prozac0401/WebSim/pull/117)의 `0172af6`이다. 두 PR의 공통 기준 `f04c9cf`에서 달라진 문구를 비교하고, 현재 main의 방 배치·다친 쪽·저장 호환 동작을 유지하며 합쳤다. 최신 통합 검증은 아래 과거 PR 검증과 구분한다.

## 통합 원칙

`scenario-scenes.js`, `day-rhythm.js`, `story-engine.js`의 이야기와 `saturday-app.js`, 시작 화면의 안내를 검토했다. 명사 위주의 보고체를 실제 행동으로 풀고, 독백에서 시스템 조건을 설명하던 부분을 줄였다. 자연스러운 대화와 기존 유머는 유지했다. 문장을 쉽게 만들기 위해 인물이 하지 않은 행동이나 알지 못하는 사실을 덧붙이지 않았다.

- 사용자가 지정한 쉬기 선택 **“이제부턴 휴식을 취한다”**를 유지했다. PR #117의 “이제는 편하게 쉰다”보다 명시된 요청이 우선한다.
- “친구”, “픽업하러 온다”와 기존 택시·픽업 표현을 유지했다. “동행”·“동승”으로 되돌리지 않았다.
- 본문·선택지·일지·그림 설명이 같은 행동을 가리키게 했다. 포장 음식은 가게에 남고 빈손으로 돌아오는 경로, 아직 받지 못한 물·식기, 결제·카드 회수의 완료 여부를 유지했다.
- 시작 전 도입은 “한쪽 다리”로 설명하고, 시작 뒤에는 저장된 다친 쪽에 맞춘다. 현재의 방 배치·인물 외형·다친 쪽 설명과 일곱 번의 추출 순서도 유지했다.

## 진행·저장 검토 범위

문구 통합은 선택 ID·분기·시간·에너지·기분·몸 상태의 수치 효과·장면 순서·결말 판정·저장 스키마를 바꾸는 작업이 아니다. 새 하루의 일곱 번 추출과 외형·방·다친 쪽 보존, 이전 기록의 누락 필드 보존을 유지한다. 기존 선택 ID를 재현하는 현재 버전 기록에서는 다듬어진 문구가 표시될 수 있다.

문구를 직접 찾는 테스트는 확정된 표현에 맞추되, 결제·빈손 귀가·미수령 상태·부상측·기록 복원의 동작 단언은 유지한다. 변경 전후 상태 비교에서는 대사와 표시용 요약을 구분하며 전체 경로를 검사하지 않았다면 전수 검증으로 표현하지 않는다.
