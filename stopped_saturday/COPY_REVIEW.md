# 《멈춘 토요일》 한국어 문체 검토

2026-10-25 · 기준 main: `f04c9cfbbf41f5086d71286f78b3048c3e7ba6ec` (PR #115 포함)

## 검토 기준

`scenario-scenes.js`, `day-rhythm.js`, `story-engine.js`의 현재 이야기와 `saturday-app.js`, 시작 화면의 안내 문구를 검토했다. 자연스러운 기존 대사와 유머는 유지하고, 장면보다 시스템의 조건을 설명하던 문장과 명사 위주의 보고체를 우선 다듬었다.

| 구분 | 수정 전 | 수정 후 또는 판단 |
| --- | --- | --- |
| 독백 | 문을 잡아 줄 사람은 아직 정해지지 않았다. | 도착했다고는 알렸는데, 나는 아직도 문 앞이다. |
| 대화 | “저기요, 문을 잠깐 잡아 주시겠어요?” | 유지. 낯선 사람에게 말을 꺼내는 상황과 높임말이 자연스럽다. |
| 선택지 | 직원에게 고정된 바닥으로 가는 길을 묻는다 | 직원에게 에스컬레이터 없이 가는 길을 묻는다 |
| 선택지 보충 | 거래를 멈춘 뒤 카드와 결제 정리 | 계산은 잠깐 멈추고 카드부터 받기 |
| 선택 후 반응 | 뒤에서 줄이 움직이는 소리가 들린다. | 뒤에서 기다리던 사람들이 한 걸음씩 다가온다. 발소리에 나도 모르게 몸을 비킨다. |
| 선택 후 반응 | 기다리는 동안 뒤쪽의 줄 소리가 다시 들린다. | 뒤에서 신발 끄는 소리가 또 난다. |
| 일지 요약 | 개인 행동: 이용 중단·귀가 / 환경: 미해결 입구를 통과하지 않음 | 좁은 입구로 들어가지 않고 귀가 / 카트와 대기 줄은 그대로 |
| 그림 설명 | 결제대에서 회수한 카드를 확인하고 다음 동선을 고른다. | 계산대에서 카드를 챙기고 앉을 자리를 찾는다. |
| 결과 비교 | 말로 꺼낸 요청 N회 | 부탁하거나 물어본 횟수 N회 |
| 띄어쓰기 | 앉을 자리만 잡는데도 | 앉을 자리만 잡는 데도 |

‘파일명: 최종_아님’, 팔이 여덟 개인 문어를 보며 물컵·휴대폰·목발을 떠올리는 장면, 유리에 비친 양말 사진은 그대로 두었다. ‘물컵 원정대’의 무거운 문과 미지근한 물도 유지하면서, 오늘 실제로 겪은 일과 상상한 설정을 구분하는 설명을 독백으로 바꿨다.

시간·거리·요청 횟수, 확인/미확인 같은 짧은 정보 표시는 목적에 맞으면 유지했다. 대사를 모두 구어체로 바꾸거나 모든 요약을 긴 서술로 늘리지는 않았다.

## 동작과 저장

- 선택 ID, 시간 계산, 분기 조건, 수치 효과, 장면 순서, 결말 판정은 변경하지 않았다.
- 저장 스키마와 버전, legacy v2 파일을 변경하지 않았다. 기존 선택 ID로 현재 이야기를 재생하면 다듬어진 문구가 표시된다.
- PR #115의 외형 무작위 선택과 애니메이션 변경을 포함한 최신 main에 적용했다. 시작 안내에도 인물 외형에 관한 기존 설명을 유지했다.
- 이전 문구를 직접 찾던 Node 단언 2곳과 브라우저 단언 2곳은 새 표현으로 갱신했다. 음식은 가게에 남고 빈손으로 귀가하는 상태, 키오스크 미주문 상태 등 동작 단언은 유지했다.

브라우저 검사에는 로컬 정적 서버를 함께 실행하고 `WEBSIM_URL=http://127.0.0.1:8766/`를 사용했다. 실행 파일이 없는 최초 시도는 검증 결과에 포함하지 않았으며, Chromium 준비 후 재실행했다. 이전 표현을 찾던 검사 실패는 위 기대 문구 갱신 후 재검증했다.

동작 비교는 6개 시나리오 × 문 3종 × 층간 이동 2종 × 주문 2종 × 도움 2종 × 휴대전화 결제 2종 × 경로 10개에서 각 12번 선택을 진행했다. 제공되는 선택 ID와 효과, 분기, 시간, 에너지·기분·몸 상태, 문맥 상태, 결말 ID가 같았다. 전체 선택 조합의 완전 탐색은 아니다.

브라우저 자동검사는 저장·새로고침·분기 일지·내보내기/가져오기·구버전 기록·모바일 터치·키보드·동작 줄이기·무작위 문/에스컬레이터/키오스크 경로를 포함하며 JavaScript/콘솔 오류는 없었다. 집중 화면의 한국어 줄바꿈은 별도로 육안 확인했다. 실제 Android/iOS 기기와 배포 사이트 검증은 수행하지 않았다. 자동검사를 사람의 재미 평가로 간주하지 않는다.
