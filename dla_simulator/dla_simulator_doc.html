입자 모양 성장 실험 DLA 사용법

무작위로 걷는 입자가 접촉해 붙으며 가지를 만드는 과정을 봅니다.

처음 세 단계

  1. 시작을 눌러 중앙의 씨앗에서 가지가 자라는 모습을 봅니다. 100개 시도는 멈춘 상태에서 입자 100개만 계산합니다.
  2. 일시정지하고 조건 하나를 바꾼 뒤 초기화합니다. 같은 난수 시드와 같은 총 시도 수에서 모양을 비교합니다.
  3. 관찰할 때 멈추고 PNG 저장을 눌러 600×600px 그림을 저장합니다.

결과 읽기

붙은 입자는 씨앗 이후 추가된 수이며 씨앗 포함 개수와 성공률을 함께 표시합니다. 총 시도는 붙거나 제거된 모든 입자 수입니다. 최대 반경은 중심부터 가장 먼 입자의 거리입니다.

처리 속도는 기기의 계산 성능이지 실제 물질의 성장률이 아닙니다. 색은 붙은 순서입니다. 같은 총 시도 수로 비교하면 서로 다른 컴퓨터 속도를 실험 결과와 혼동하지 않을 수 있습니다.

조건 바꾸기

접촉하면 붙을 확률은 0~1입니다. 4방향과 8방향은 이동 방향·접촉 이웃을 함께 바꿉니다. 방향 선호 0은 무작위이며 0°는 오른쪽, 90°는 아래쪽입니다.

시드를 바꾸면 멈추고 새 씨앗으로 초기화합니다. 다른 설정은 다음 시도부터 바뀌므로 비교를 위해 초기화하세요. 초기화는 현재 조건의 시드에서 다시 시작하며 실행도 멈춥니다.

제작 원리와 학술적 의미

확산 제한 응집의 의미

Witten과 Sander의 DLA는 멀리서 확산해 온 입자가 기존 응집체에 붙으며 생기는 무작위 가지 구조를 연구하는 성장 모형입니다. 바깥 가지가 입자를 먼저 만나 안쪽이 가려지는 차폐 효과가 조밀하지 않은 구조를 만듭니다. Witten·Sander (1981), Physical Review Letters 47, 1400

이 구현은 중앙 씨앗·격자 무작위 이동·접촉 부착의 유한 격자 DLA입니다. 붙을 확률 1, 방향 선호 0, 4방향이 기본입니다. 확률을 낮추거나 방향 선호를 더하면 원형 모형의 변형 조건이 됩니다. 결정 성장의 온도·농도·물질 확산 계수는 계산하지 않습니다.

경계와 재현성

입자는 현재 최대 반경+출발 여백의 원에서 출발합니다. 최대 반경+제거 여백을 벗어나면 제거하며, 실제 제거 여백은 출발보다 최소 한 칸 큽니다. 무작위 이동은 한 입자당 최대 20,000번으로 제한합니다. 기존 응집체가 차지한 칸으로는 이동할 수 없습니다.

600×600 격자에서 출발 원이 경계에 닿기 전에 실행을 멈춥니다. 출발·제거 경계와 이동 상한은 무한 공간 DLA를 계산하기 위한 근사이므로 이 설정까지 같게 유지해야 공정하게 비교할 수 있습니다.

mulberry32 난수 시드와 같은 조건을 쓰면 같은 총 시도 수의 무늬를 재현합니다. 계산 묶음은 화면에 전달하는 시도 수이며 물리 조건을 바꾸지 않습니다. FPS에 따라 설정값을 몰래 줄이던 자동 변경을 제거했고, Worker는 묶음 사이에 메시지를 처리합니다.

개발 구성

TypeScript와 Web Worker로 계산합니다. npm test는 이웃·제거 경계·방향 편향을 검사하고 npm run build는 공개 실행본을 만듭니다. index.html은 Vite 개발 진입점, standalone.html은 공개 실행본입니다.
