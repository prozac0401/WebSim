- 실제 HTML이 지정한 `?v=20261025-brake-lights-1`을 붙인 렌더링 코드 4개와 수프라·GR86 모델 2개도 별도로 비교했다. 6/6 일치. URL·SHA256·응답 캐시 헤더는 [served-bytes.json](served-bytes.json)에 보존했다.
- 공개 브라우저 DOM에서도 위 버전 번호가 붙은 스크립트를 확인했다. 새로고침 후 수프라 화면이 다시 준비되고 주행 조작이 가능한 것을 확인했다.
- 응답은 `Cache-Control: max-age=600`이었다. 이 관찰은 현재 서버 파일의 일치를 확인하며, 이미 열려 있는 사용자의 탭이나 모든 기기의 캐시까지 검사한 것은 아니다. 관련 코드에서 Service Worker 등록은 발견되지 않았다.
- 수프라·인제·시드 31415·8대·예산 30에서 1초 진행 버튼으로 8초와 13초 화면을 확인했다. 8초는 120 km/h, 감속 중, +5.6%; 13초는 89 km/h, 가속 중, −3.0%로 표시됐다. [8초 공개 화면](public-supra-8s.jpg), [13초 공개 화면](public-supra-13s.jpg).

공개 화면의 감속 라벨은 실제 차륜 제동력 그 자체가 아니다. 브라우저 내부 차륜 힘을 직접 읽거나 변경하지 않았다. 동일 코드의 별도 결정론적 참조 실행은 8초에 약 15.9 kN/점등, 13초에 제동력 0/소등이었으며, 이것을 공개 브라우저 내부 계측 결과로 취급하지 않는다.

## 확인한 표시 문제와 수정

기존의 일부 내부 광학 부품은 바깥 렌즈에 가려지고, 일부 넓은 커버 태그는 실제 광학 가이드보다 넓은 면을 발광시켰다. 원본 모델의 광학 가이드 윤곽을 해당 렌즈 표면으로 투영한 점등 전용 형상을 추가했다. 원본 정점·노멀·UV·색·투명도·텍스처 데이터는 수정하지 않는다. 투영은 로딩 때 한 번 계산하고, 점등 시에도 깊이 검사를 유지한다. 반사판 위에 사각형이나 후광을 덮지 않는다.

| 차종 | 변경 |
|---|---|
| G70·G80 | 기존 LED 태그와 밝기 유지. 고정 후면 비교에서 OFF/ON 각각 변경 픽셀 0 |
| 수프라 | 외측 원본 가이드와 뒤 유리 안의 보조 제동등을 자기 렌즈 표면에 표시. 원본에서 이미 밝은 빨강이던 가이드의 OFF 표시를 어둡게 해 점등과 구분 |
| GR86 | 넓은 커버 발광 대신 C자 원본 가이드 사용. 중앙 투명 구간을 제외하고 OFF 가이드 밝기 보정 |
| K5 | 넓은 커버 대신 원본 가이드 윤곽을 표시. 불필요한 발광 면적을 줄임 |
| 아반떼 N | 원본 외측 상부 가이드를 렌즈 표면에 표시. 하부·가운데 구간 제외 |
| 모닝 | 내부 불투명 부품에 실제로 가려진 램프 뒷면은 투영하지 않아 가운데 구간을 채우지 않음. 외측 광학 패턴과 보조 제동등 표시 개선 |
| 스타리아·아이오닉 5·싼타페·카니발 | 원래 픽셀/H형/외측 가이드 윤곽을 유지하며 렌즈 감쇠·가림 보정 |

| 토레스 | 기존 사진 정합 6개 세로 요소+보조 제동등의 영역 유지. 공통 점등 색 보정 적용. 아래 네이티브 사진 투영 비교에서는 제외 |

G70/G80을 제외한 점등은 LDR 화면에서 식별하기 쉬운 밝은 빨강으로 보정했다. 투명한 보조 제동등은 켜질 때만 불투명도를 높인다. 이 수치는 실제 광도(cd)나 조도(lx)의 실측/인증 값이 아니다. [기존 모델별 출처·라이선스](../../MODEL-SOURCES.md)를 유지한 원본 모델 형상에 기반한 표시 개선이며 차량별 국내 트림의 실제 등화 회로 전체를 새로 실측했다는 뜻도 아니다.

차륜 힘 판정, 히스테리시스, 0.18초 유지, 물리·카메라·차량 모델 파일은 변경하지 않았다. 모델 로더를 포함한 변경 런타임 4개의 캐시 버전은 `20261026-brake-lens-2`이다.
