# 태백 스피드웨이 연석·방호시설 표현 근거

2026-10-27 검토. 사용자가 제공한 주행 영상에서 보이는 연석·잔디띠·방호시설을 기존 코스 좌표에 대조했다. **재포장 후 모습이라는 영상 작성자의 설명을 참고한 표시 모델**이며, 포장 공사일이나 현재 시설 전체를 측량한 자료는 아니다. 최종 적용 구간·좌표·색·출처 ID는 [taebaek-features.json](korea/taebaek-features.json)의 `sources`, `features`, `metadata`가 기준이다.

거리 구간은 현재 모형의 **시계방향 중심선 2,322m** 기준이다. 공용 주행선은 약 **2,282.026m**이고 차량별 선택 주행선도 달라지므로 `car.distance`와 혼용하지 않는다. 로컬 좌표는 동쪽 `+x`, 남쪽 `+y`이며 원점은 `[129.0182351, 37.0827744]`에서 시작한다. 현재 도로의 **명목 폭 14m는 기존 모형값**이지 이번 영상에서 측정한 실제 폭이 아니다.

영상에는 위치를 정량적으로 맞출 미니맵·속도 기록이 없어 코너 순서와 주변 건물·절벽을 대조했다. 아래 시작·끝은 대략 **25–50m 수준의 위치 여유가 있는 추정**이며, 횡방향 이격·연석 폭·레일 높이·기둥 간격·색도 표시용 근사다. 이번 주변 표현은 원본 평면 경로·길이·고도·차량 주행선을 변경하지 않는다.

## 연석: 관찰한 쪽만 표시

일반 직선과 확인한 코너 바깥은 흰 가장자리선을 기본으로 두고, 영상에서 적백 연석이 보이는 쪽만 추가한다. 이는 보이지 않는 모든 바깥 연석이 실제로 없다는 주장과 다르다. 연석 뒤의 갈색 영역은 토양·마른 잔디가 섞여 보이며, 이를 검증된 모래·자갈 런오프라고 분류하지 않는다.

금속레일 앞에 보이는 잔디띠와 코너 바깥의 넓은 잔디 공간을 남긴다. 레일을 연석 바로 옆으로 일률 배치하거나 모든 경계를 같은 벽으로 만들지 않는다.

피트 쪽 콘크리트벽은 [기존 피트 데이터](../pits/taebaek.json)를 사용하며 새 주변 방호시설과 중복 배치하지 않는다. 원본의 그림자·차량 타이어 자국을 노면 도장이나 새로운 시설로 해석하지 않는다.

## 자료 이용과 검증 범위

원본 영상·사진·추출 프레임은 무시되는 로컬 `output/`에서 검토하며 제품 이미지·텍스처로 재배포하지 않는다. 태백시 사진은 공공누리 제4유형으로 표시되어 있고, 이번에는 현장 형태를 확인하는 참고 자료로만 사용한다. OSM 파생 좌표에는 **© OpenStreetMap contributors**, [ODbL-1.0](https://opendatacommons.org/licenses/odbl/1-0/)을 적용한다.

이 문서는 출처와 배치 판단을 기록한 것이며 전체 실물 기하의 정확성, 안전시설 규격 또는 실제 주행 성능을 인증하지 않는다. 적용값은 [실행 데이터 JSON](korea/taebaek-features.json), 기존 도로·고도 가정은 [SOURCES.md](../../SOURCES.md)를 따른다.
