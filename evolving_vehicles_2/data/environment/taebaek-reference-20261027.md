# 태백 스피드웨이 연석·방호시설 표현 근거

2026-10-27 검토. 사용자가 제공한 주행 영상에서 보이는 연석·잔디띠·방호시설을 기존 코스 좌표에 대조했다. **재포장 후 모습이라는 영상 작성자의 설명을 참고한 표시 모델**이며, 포장 공사일이나 현재 시설 전체를 측량한 자료는 아니다. 최종 적용 구간·좌표·색·출처 ID는 [taebaek-features.json](korea/taebaek-features.json)의 `sources`, `features`, `metadata`가 기준이다.

## 주변 산지·절개지 보완

추가 검토에서는 주행 노면을 더 가파르게 만드는 대신, 영상의 가까운 절개지와 숲이 덮인 주변 산지를 보완했다. 메인 직선 00:20–00:30의 오른쪽 큰 산은 두 평행 도로 사이가 아니라 **반대편 복귀로 너머**에 있다. 복귀로 00:50의 왼쪽 절개지와 마지막 코너 01:50의 바깥 왼쪽 절개지가 가까운 지형의 주된 근거다. 영상 05:40의 높은 블록벽은 본선에서 빠져 피트로 들어가는 별도 접근로에 있으므로 메인 코스 방호벽으로 옮기지 않는다.

주변 높이는 [Open-Meteo 고도 API](https://open-meteo.com/en/docs/elevation-api)를 통해 [Copernicus DEM 2021 GLO-90](https://doi.org/10.5270/ESA-c5d3d65)에서 **391점(23×17)을 75m 간격으로 조회**했다. 원본 값은 **575–896m AMSL, EGM2008 기준**이며 누락값을 만들어 넣지 않았다. 로컬 범위는 `x=-850…800m`, `y=-700…500m`다. 75m는 조회 간격이고 원 자료 해상도는 약 **90m**이므로 더 세밀한 실측 지형이 된 것은 아니다. DSM에는 수관·건물·과거 지표가 포함될 수 있다.

표시 지형은 격자 사이를 이중선형 보간하고 기존 고도 표시 배율 **1.75를 한 번만 적용**한다. 모든 도로 구간 주변에서 약 **40m 연결 범위**로 기존 노면 높이에 부드럽게 맞추며, 코스 내부와 피트 영역은 주변 산지 적용에서 제외한다. 도로 가까운 지형은 최대6m 간격으로 나누고 도로 외곽 약8m의 지지면을 안정화해, 가드레일이 거친 격자를 따라 출렁이지 않도록 한다. 이8m는 실측 갓길 폭이 아닌 표시 지형의 연결 조건이다. 이는 도로·차량의 기존 물리 고도를 보존하기 위한 표시상 연결이며, 실제 절개지 경사를 측량해 복원한 방식은 아니다. 원본 격자값·출처·조회 정보는 실행 데이터에 기록한다.

숲의 평면 범위는 [OSM 산림 관계 8057853](https://www.openstreetmap.org/relation/8057853)의 [외곽선 655059092](https://www.openstreetmap.org/way/655059092)을 잘라 사용한다. 해당 외곽선의 편집 시점은 2020-07-15다. 코스·피트와 두 직선 사이의 빈 영역을 숲으로 채우지 않으며, 지형 재질을 표시하는 넓은 범위와 나무를 생성하는 가까운 범위를 구분한다. 남·북의 분리된 단순 다각형을 사용하고 잘라낸 경계를 임의 직선으로 연결해 코스 내부를 덮지 않는다. **개별 나무 위치·높이·수관·밀도는 영상 인상을 바탕으로 한 추정**이다.

복귀로 왼쪽 620–820m와 마지막 탈출부 왼쪽 1930–2025m의 바위색 패치는 영상에서 노출된 절개지의 재질을 표현한다. 기존 지형 면에 맞춘 색 구분이며 정밀한 암벽 형상·지질·사면 공법이 확인된 것은 아니다. 새로 취득한 DEM과 기존 노면을 연결한 결과 역시 실제 현장 측량으로 표기하지 않는다.

## 자료 이용과 검증 범위

원본 영상·사진·추출 프레임은 무시되는 로컬 `output/`에서 검토하며 제품 이미지·텍스처로 재배포하지 않는다. 태백시 사진은 공공누리 제4유형으로 표시되어 있고, 이번에는 현장 형태를 확인하는 참고 자료로만 사용한다. OSM 파생 좌표에는 **© OpenStreetMap contributors**, [ODbL-1.0](https://opendatacommons.org/licenses/odbl/1-0/)을 적용한다.

고도 자료는 Open-Meteo / Copernicus DEM GLO-90 (2021), European Union and ESA를 표기하며, Open-Meteo의 [CC BY 4.0 안내](https://open-meteo.com/en/licence)와 Copernicus DEM 이용 조건을 따른다. 원 API 응답·조회 좌표·해시는 로컬 근거 자료로 보존하고 제품에는 필요한 격자와 출처를 포함한다.

이 문서는 출처와 배치 판단을 기록한 것이며 전체 실물 기하의 정확성, 안전시설 규격 또는 실제 주행 성능을 인증하지 않는다. 적용값은 [실행 데이터 JSON](korea/taebaek-features.json), 기존 도로·고도 가정은 [SOURCES.md](../../SOURCES.md)를 따른다.
