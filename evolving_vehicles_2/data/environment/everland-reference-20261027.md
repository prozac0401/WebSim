# 용인 에버랜드 스피드웨이 주변·노면 표현 근거

2026-10-27 검토. 사용자가 제공한 주행 영상과 운영사 사진을 현재 코스 좌표에 대조했다. **2023년 초봄 모습에 2024년 사진에서 확인한 일부 시설을 보완한 표시 모델**이며, 2026년 현장 측량이나 안전시설 도면을 재현했다는 뜻은 아니다. 실제 적용 구간·좌표·색·출처 ID는 [everland-features.json](korea/everland-features.json)의 `sources`, `features`, `metadata`가 기준이다.

## 시작선·그리드·거리 표지판

체크무늬 시작·결승선은 공식 사진에서 확인했다. 표시 위치 **중심선 1,582m**는 영상의 타이밍 지점과 맞춘 근사이며 시뮬레이터 거리 원점과 별개다. 물리 출발·랩 계측 원점과 원래 도로 고도는 바꾸지 않는다.

흰 열린 그리드 브래킷은 공식 사진과 영상 02:15·02:20에서 보인다. 구현한 **18개와 규칙적인 간격은 표시용 추정**이다. 실제 그리드 총수·간격·읽히지 않는 바닥 번호를 확인한 것으로 취급하지 않는다. 우측의 가는 노란 피트 합류선도 관찰 범위에만 표시하며 전체 점선 출구 형식을 확정하지 않는다.

## 지형 표현과 자료 이용

북쪽 숲은 [OSM 관계 9180929](https://www.openstreetmap.org/relation/9180929), 남쪽 숲은 [378244242](https://www.openstreetmap.org/way/378244242)의 경계 안에서 표시 범위를 제한했다. 이전 저해상도 사진 추정 경계를 그대로 늘리지 않는다. [수목열 614535238](https://www.openstreetmap.org/way/614535238)은 배치선의 근거이며 개별 나무 측량은 아니다. [연못 671420798](https://www.openstreetmap.org/way/671420798)은 수목 배제 구역으로 보존하고 확인되지 않은 수면 고도를 만들지 않는다.

피트 뒤 패독은 운영사 사진에서 포장을 확인한 **보수적인 안쪽 다각형**이며 경계에는 약 20m 불확실성이 있다. OSM 시설 전체의 `surface=asphalt`를 패독 범위로 쓰지 않는다. 패독과 필요한 포장 재질은 `drapeOnTerrain`으로 기존 지형 면에 맞춰 칠한다. 기본 지면색과 같은 잔디 구역은 `baseMaterial`로 별도 중첩 면을 생략하면서 수목 배제 범위는 유지한다. 따라서 서로 다른 높이의 면이 겹쳐 잔디 조각이 포장 위로 드러나는 현상을 줄인다. 이는 표시 처리이며 원래 도로·물리 고도를 고치는 작업이 아니다.

원본 사진·동영상·추출 프레임은 무시되는 로컬 `output/everland-trackside-qa/`에서 검토하며 제품에 재배포하지 않는다. OSM 파생 좌표는 **© OpenStreetMap contributors**, [ODbL-1.0](https://opendatacommons.org/licenses/odbl/1-0/)을 따른다. 출처별 날짜·링크·해시와 최종 적용값은 [실행 데이터 JSON](korea/everland-features.json)을 확인한다. 세부 처리 코드는 [환경 생성기](../../track-environment.js), [도로 표지판](../../trackside-boards.js)에 있다.
