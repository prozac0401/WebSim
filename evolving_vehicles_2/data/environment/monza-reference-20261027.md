몬차의 자갈·포장 런오프와 벽면 광고는 [F1 24 게임 가이드 영상](https://www.youtube.com/watch?v=ca5pPA1_Vks)을 위치·외관 참고로 삼고, 실제 2024년 FIA 변경 기록과 Formula 1 사진으로 구분했다. 영상은 2025-02-12 업로드된 208초 게임 화면이며 실제 주행 촬영이나 2025년 시설 측량 자료가 아니다. 게임 제목의 연도만으로 재포장 이후 모든 변경이 반영됐다고 보지 않는다.

## 적용과 추정의 경계

첫 시케인·로지아·레즈모·아스카리의 게임상 자갈 위치는 별도 시각 근거로 기록하고, 실제2024 FIA 추가 자갈띠는 독립 근거로 구분한다. 서로 반대편에 보이는 기존 자갈과 신설 띠를 하나의 넓은 자갈 구역으로 합치지 않는다. 파라볼리카는 확인되는 자갈과 아스팔트 런오프를 나누며, 갈색 잔디를 자막이나 색만으로 자갈로 바꾸지 않는다.

구간의 시작·끝, 외곽 다각형, 벽까지의 거리·높이와 광고 반복 간격은 표시용 근사다. FIA가 명시한 자갈띠의 폭·이격 외에는 측량 치수로 주장하지 않는다. 거리는 차량별 주행선이 아닌 기존5,793m 코스 중심선 기준이며, 게임 화면의 거리·시점과 직접 동일시하지 않는다. 원본 도로 XY·길이·고도·주행 물리는 유지한다. 지표 재질은 기존 표시 지형에 맞추며 자갈 표시가 물리적인 탈출·감속 구역을 새로 계산한다는 뜻은 아니다.

광고는 대회별 임시 배치일 수 있다. 게임에서 읽힌 브랜드와 실제2024 사진의 브랜드가 다르면 자료 시점을 구분하고, 사진으로 확인되는 위치는 실제 자료를 우선한다. 파라볼리카 내측의 게임상 ROLEX를 실제2024 Workday의 근거로 쓰지 않는다. 글자와 색상은 기하 글리프로 근사한 워드마크이며, 공식 로고 원본이나 광고판의 정확한 서체·비율을 복제한 것이 아니다. 벽 재질·브랜드 표시가 모터스포츠 주최자나 상표권자의 제휴·승인을 의미하지 않는다.

메인 직선의 기존 피트벽은 같은 좌표를 유지해 환경 데이터로 옮기고 광고를 한 번만 그린다. 기존 피트 시설에 동일한 벽을 남겨 겹쳐 표시하지 않는다. 상세 근거·구간·추정 치수는 [몬차 환경 JSON](overseas/monza-features.json)이 기준이며, 기존 피트 시설은 [몬차 피트 JSON](../pits/monza.json)을 따른다.
