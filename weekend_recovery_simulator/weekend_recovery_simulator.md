# 주말 회복 플래너 (주말 회복 시뮬레이터)

이 도구는 **테스트형 문답**이 아니라, 토/일 시간표를 직접 배치해보는 **계획형 시뮬레이터**입니다.

## 핵심 아이디어

- 같은 주말 일정이라도 결과가 다른 이유를 `몸 회복 / 사회적 소모 / 이동 피로 / 미해결 압박` 4축으로 나눠서 보여줍니다.
- 블록을 배치하면 회복 곡선이 즉시 변하고, 점수뿐 아니라 **문장형 해석**(진단 1줄 + 핵심 원인 1줄 + 에세이 문장 1줄)을 제공합니다.
- 자동 추천안 3종(외출 몰기형, 회복 버퍼형, 수면 보호형)을 미리보기/적용하며 “이걸 바꾸면?”을 확인할 수 있습니다.

## 사용 방법

1. 주말 목표를 선택합니다.
2. 토/일 타임라인에 활동 블록을 드래그해 배치합니다.
3. 블록의 위/아래 핸들을 드래그해 길이를 늘리거나 줄입니다.
4. 오른쪽 결과에서 회복 곡선과 4축 점수를 확인합니다.
5. 추천안을 눌러 비교(점선) 후, 마음에 드는 안을 적용합니다.

## 시간대 제한 블록

- `브런치 약속`: 09:00~14:00 범위에서만 배치 가능
- `밤늦게 폰 보기`: 22:00~24:00에서만 배치 가능
- `일찍 눕기`: 20:00~24:00에서만 배치 가능

## 신규 활동 블록

- `가족과 함께 외식`
- `운전`

## 계산 포인트

- 기본식은 `수면 회복 + 혼자 시간 회복 - 사회/이동/압박/야간 스크린 비용` 구조를 따릅니다.
- 이동 시간, 약속 전환, 밤 스크린 누수 같은 “숨은 비용”이 결과에 반영됩니다.

블로그 글에서는 점수 자체보다,  
“왜 이번 주말이 덜 회복적이었는지”를 해석하는 문장을 중심으로 연결하면 가장 잘 맞습니다.
