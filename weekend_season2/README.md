# 주말 계획표 시즌2

자동으로 만난 가상 인물의 한 해를 살아가는 1인용 생활 게임입니다. 시작 연도는 2026~2100년 중 고를 수 있습니다. 인생 소개를 읽고 좋아하는 일을 여러 개 고르면, 자동 모드가 일정과 사건의 선택까지 맡아 한 해를 보냅니다. 중요한 선택만 직접 하는 방식도 고를 수 있습니다. 생활공간, 가족 삽화, 취미 결과물과 연말 회고를 제공합니다. 단일 행복 점수나 승패 기준은 없습니다. 기존 주말 회복 플래너는 그대로 남습니다.

## 실행

저장소 루트에서 정적 서버를 실행합니다. 별도 설치·빌드·계정·Secret이 필요하지 않습니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

`http://127.0.0.1:8000/weekend_season2/index.html`을 엽니다. 홈 목록과 기존 실험의 다른 실험 메뉴에서도 진입할 수 있습니다. 공개 배포 주소는 [주말 계획표 시즌2](https://prozac0401.github.io/WebSim/weekend_season2/index.html)이며, 기존 GitHub Pages 설정(`main` 브랜치의 루트)을 사용합니다.

1. 자동 배정된 인물의 소개를 읽고 시작 연도를 고른 뒤 **이 삶으로 시작**합니다. **다른 삶 만나기**로 새 인물을 만날 수도 있습니다.
2. **하고 싶은 일 고르기**에서 공부·취미 등 여러 활동을 고른 뒤 **자동으로 살아보기**를 누릅니다. 선택한 일을 돌아가며 배치하고 휴식·집안일도 챙깁니다. 같은 버튼으로 일시정지할 수 있습니다.
3. 기본 자동 모드는 반복 예약을 확정하고, 시간이 모자라거나 예산이 부족하면 일정을 옮기거나 무료 활동으로 바꿉니다. 사건의 선택도 맡겨 둘 수 있어 연말까지 다시 누를 필요가 없습니다. **중요한 선택은 직접 할게요**를 켜면 중요한 장면에서 기다렸다가 선택 후 다시 이어갑니다.
4. **이번 주 조금 더 챙기기**에서 활동 한 번을 더하거나, **날짜를 직접 정하고 싶다면**에서 달력과 반복 일정을 조정합니다. **평일 저녁, 나만의 수업**은 고른 요일의 저녁을 그대로 예약합니다.
5. 연말에는 실제 기록으로 만든 회고를 읽습니다. 수동 환경 설정과 기존 네 프리셋은 시작 화면의 접힌 상세 설정에 있습니다.

브라우저 자동 저장과 버전 있는 JSON 내보내기·가져오기를 제공합니다. 현재 진행을 덮어쓰는 가져오기와 새 게임은 확인을 거칩니다. 네트워크로 게임 데이터를 전송하지 않습니다. 개인정보와 계좌를 연결하지 않으며 분석 SDK도 없습니다.

계산 모듈은 CommonJS와 브라우저 전역을 모두 지원하며 DOM 없이 검사할 수 있습니다. 계산과 장식 시간은 분리합니다. `render_game_to_text()`는 현재 화면 상태, `advanceTime(ms)`는 장면 시간 검사용입니다. 실제 날짜는 플레이어 진행 조작으로만 변합니다.

## 자료와 한계

새 인생은 지역별 인구·근로소득 구간의 공개 분포를 사용하며, 이름·성씨의 제한된 목록과 창작 가족·외형·생활비 모델을 조합합니다. 수도권 추첨 비중은 약 50.86%입니다. 인구는 미성년자·거주불명자·재외국민 포함/외국인 제외, 소득은 연말정산 신고자라는 서로 다른 모집단입니다. 따라서 생성된 인생 전체를 한국인의 대표 표본으로 해석하면 안 됩니다. [상세 출처·추출 방법](weekend_season2_doc.html#life-sources)에 원표와 한계를 기록했습니다.

급여는 2024년 귀속 세전 연간 총급여의 12개월 환산이며 재직 월급·실수령액이 아닙니다. 닫힌 구간 안의 균등 분포, 연10억원초과 구간의 게임 대표 월1억원, 구직자·대학원생·돌봄 지원비 비율30%·50%·65%는 명시한 게임 가정입니다. 시작 고정비는 월수입의45~70%, 시작현금40~180%, 개인예산은 고정비를 뺀 금액의55%, 카드한도는 월수입50%(최소10만원/최대500만원)로 생성하며 실제 가계지출 분포를 추정한 값이 아닙니다. 이전 저장에는 새 배정을 적용하지 않습니다.

공휴일의 날짜·출처·확인일은 `calendar.js`의 `holidaySources`에 있습니다. 2025년 최초 발표 이후의 2026년 노동절·제헌절 변경도 공식 자료로 확인했습니다. 지역별 공휴일이나 직장별 근무일은 반영하지 않습니다.

남·여 커트는 한국소비자원 참가격의 2026년 9월 16개 지역 조사값을 사용합니다. 세종은 같은 달 자료가 확인되지 않아 게임 기본값을 표시합니다. 부산 펌·염색 한 업체와 서울·부산 저녁 강좌 사례는 지역 평균이 아닙니다. 강좌는 전체 수강료·재료비·선택 대여료를 표시하고 회당 환산합니다. 미확인 활동에는 임의 지역 배율을 적용하지 않습니다. 자료 시점의 비용을 모든 게임 날짜에 고정 적용하며 실제 예약·수업 종류·운영 요일·선결제 조건은 재현하지 않습니다. [가격 출처와 범위](weekend_season2_doc.html#activity-prices)를 확인할 수 있습니다.
