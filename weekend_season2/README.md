# 주말 계획표 시즌2

가상 환경을 설정하고 대한민국 2026년의 주말·연휴·평일을 날짜순으로 살아가는 1인용 생활 게임입니다. 생활공간, 취미 결과물, 월별 기억과 연말 회고를 제공합니다. 단일 행복 점수나 승패 기준은 없습니다. 기존 주말 회복 플래너는 그대로 남습니다.

## 실행

저장소 루트에서 정적 서버를 실행합니다. 별도 설치·빌드·계정·Secret이 필요하지 않습니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

`http://127.0.0.1:8000/weekend_season2/index.html`을 엽니다. 홈 목록과 기존 실험의 다른 실험 메뉴에서도 진입할 수 있습니다. 이 작업은 로컬 구현이며 공개 사이트에는 배포하지 않았습니다.

1. 프리셋을 선택하고 환경·수입·지출 예산·선호를 수정합니다.
2. 활동과 결제수단을 선택하고 날짜별 오전·오후·저녁에 놓습니다.
3. 반복 예약은 이동된 날짜를 확인하고 확정합니다. 충돌하면 미루기·건너뛰기·중단으로 조정합니다.
4. 이번 주를 진행하고 사건에 응답합니다. 장면과 주중 결과를 확인해 다음 주로 갑니다.
5. 빠르게 보려면 다음 중요한 선택까지 진행합니다. 연말에는 실제 로그로 만든 회고를 읽습니다.

브라우저 자동 저장과 버전 있는 JSON 내보내기·가져오기를 제공합니다. 현재 진행을 덮어쓰는 가져오기와 새 게임은 확인을 거칩니다. 네트워크로 게임 데이터를 전송하지 않습니다. 개인정보와 계좌를 연결하지 않으며 분석 SDK도 없습니다.

## 적용한 제안 기본값

| 항목 | 구현 기본값 |
| --- | --- |
| 시즌 | 대한민국 2026년 1월 1일~12월 31일, 연말 회고 |
| 날짜 | UTC 날짜 문자열, 실제 일자 생성, 일요일까지의 부분 주 |

| 다른 연도 | 날짜 엔진 대응, 공휴일 자료 미확인 표시; UI는 2026년 한 시즌 |
| 슬롯 | 오전 09–13, 오후 14–18, 저녁 18–22; 각 240분 |
| 비용과 시간 | 원화 정수, 활동+준비+왕복 이동 시간 검사 |
| 프리셋 | 직장인·구직자·대학원생·돌봄 중심의 수정 가능한 가상 환경 |

| 추가근무 | 다음 급여일 지급, 연말 미지급분은 지급 예정으로 보존 |

| 미납 | 자동 대출·즉시 게임오버 없음; 필수비용·미납 우선 처리 |
| 무작위 | 외부 사건과 행동 후속을 분리한 시드, 기본 2026 |
| 시각화 | 외부 이미지 없는 Canvas 2D 생활공간, 계절·활동·결과물 |
| 저장 | 브라우저 로컬 저장과 버전 1 JSON, 검증 후 교체 확인 |

## 코드 구조

| 파일 | 책임 |
| --- | --- |
| `calendar.js` | 날짜 산술, 휴일 데이터와 출처, 부분 주 |
| `recurrence.js` | 반복 원래 날짜·이동·완료·건너뛰기·중단 |
| `finance.js` | 원화 장부, 급여·예산·청구·미납·지급 예정 |
| `data.js` | 프리셋, 활동 사양과 게임용 효과 |
| `events.js` | 사건 문구·선택지·후속 행동 정의 |
| `engine.js` | 시간·돌봄 검사, 날짜 진행, 상태 변화와 사건·회고 로그 |
| `storage.js` | 저장 형식과 입력 검증, 복구 |
| `scene.js` | 생활공간·캐릭터·계절·취미 흔적 Canvas 표현 |
| `app.js`, `index.html`, `style.css` | 한국어 설정·계획·사건·재생·회고·저장 UI |
| `weekend_season2_doc.html` | 플레이 방법, 모형 가정, 근거 |

계산 모듈은 CommonJS와 브라우저 전역을 모두 지원하며 DOM 없이 검사할 수 있습니다. 계산과 장식 시간은 분리합니다. `render_game_to_text()`는 현재 화면 상태, `advanceTime(ms)`는 장면 시간 검사용입니다. 실제 날짜는 플레이어 진행 조작으로만 변합니다.

## 검사 명령

```powershell
node --test weekend_season2/*.test.cjs
node --test tests/new-labs.test.cjs tests/preset-scenes.test.cjs ink_time_machine/ink-flow-engine.test.cjs boids_simulation/boids-app.test.cjs
```

실제 Chromium 검사는 정적 서버와 Playwright가 필요합니다. 검사는 저장소 의존성 또는 설치된 develop-web-game 스킬의 Playwright를 사용합니다.

```powershell
$env:WEBSIM_URL = 'http://127.0.0.1:8000/'
node tests/weekend-season2.browser.cjs
```

원본 develop-web-game 클라이언트도 실행해 화면과 텍스트 상태를 교차 확인합니다. 스크린샷·결과 JSON은 `output/playwright/weekend-season2/`에 저장됩니다. 최신 정확한 실행 결과와 독립 검토 기록은 `VERIFICATION.md`에 기록합니다.

## 자료와 한계

공휴일의 날짜·출처·확인일은 `calendar.js`의 `holidaySources`에 있습니다. 2025년 최초 발표 이후의 2026년 노동절·제헌절 변경도 공식 자료로 확인했습니다. 지역별 공휴일이나 직장별 근무일은 반영하지 않습니다.

비용·이동시간·피로·기분·성과·사건 확률은 게임용 가정입니다. 프리셋은 현실 인구집단의 평균이 아닙니다. 성별로 능력·수입·돌봄을 배정하지 않으며, 주거 유형 자체로 행복 순위를 매기지 않습니다. 같은 선호·피로·경제·마감 맥락에서 선택의 결과를 읽도록 구성했습니다.

참고한 [80억 분의 1](https://1in8b.life/ko/)에서는 선택 누적과 회고 구조만 참고했습니다. 문구·이미지·사건을 복제하지 않았습니다. 첨부된 2026-10-16 설계안 v0.1과 사용자 구현 요청을 범위 기준으로 삼았습니다.

다년 이어하기, 실제 금융·의료·취업 예측, 개별 지인별 장편 서사, 여행·장기 프로젝트는 후속 범위입니다. 이동은 지역 유형과 수단에 따른 근사입니다. 30~45분 플레이 시간이나 재미, 저사양 성능은 검증했다고 주장하지 않습니다.
