# 주말 계획표 시즌2

자동으로 만난 가상 인물의 한 해를 살아가는 1인용 생활 게임입니다. 시작 연도는 한국 날짜 기준 현재 연도가 기본이며, 2026~2100년 중 고를 수 있습니다. 인생 소개를 읽고 좋아하는 일을 여러 개 고르면, 자동 모드가 일정과 사건의 선택까지 맡아 한 해를 보냅니다. 중요한 선택만 직접 하는 방식도 고를 수 있습니다. 생활공간, 가족 삽화, 취미 결과물과 연말 회고를 제공합니다. 단일 행복 점수나 승패 기준은 없습니다. 기존 주말 회복 플래너는 그대로 남습니다.

## 실행

저장소 루트에서 정적 서버를 실행합니다. 별도 설치·빌드·계정·Secret이 필요하지 않습니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

`http://127.0.0.1:8000/weekend_season2/index.html`을 엽니다. 홈 목록과 기존 실험의 다른 실험 메뉴에서도 진입할 수 있습니다. 공개 배포 주소는 [주말 계획표 시즌2](https://prozac0401.github.io/WebSim/weekend_season2/index.html)이며, 기존 GitHub Pages 설정(`main` 브랜치의 루트)을 사용합니다.

1. 자동 배정된 인물의 소개를 읽고 시작 연도를 고른 뒤 **이 삶으로 시작**합니다. **다른 삶 만나기**로 새 인물을 만날 수도 있습니다.
2. **하고 싶은 일 · 해야 하는 일**에서 공부·취미 등 여러 활동을 고른 뒤 **자동으로 살아보기**를 누릅니다. 선택한 일을 돌아가며 배치하고 휴식·집안일도 챙깁니다. 같은 버튼으로 일시정지할 수 있습니다.
3. 기본 자동 모드는 반복 예약을 확정하고, 시간이 모자라거나 예산이 부족하면 일정을 옮기거나 무료 활동으로 바꿉니다. 사건의 선택도 맡겨 둘 수 있어 연말까지 다시 누를 필요가 없습니다. **중요한 선택은 직접 할게요**를 켜면 중요한 장면에서 기다렸다가 선택 후 다시 이어갑니다.
4. **이번 주 조금 더 챙기기**에서 활동 한 번을 더하거나, **날짜를 직접 정하고 싶다면**에서 달력과 반복 일정을 조정합니다. **평일 저녁, 나만의 수업**은 고른 요일의 저녁을 그대로 예약합니다.
5. 연말에는 실제 기록으로 만든 회고를 읽습니다. 수동 환경 설정과 기존 네 프리셋은 시작 화면의 접힌 상세 설정에 있습니다.

브라우저 자동 저장과 버전 있는 JSON 내보내기·가져오기를 제공합니다. 현재 진행을 덮어쓰는 가져오기와 새 게임은 확인을 거칩니다. 네트워크로 게임 데이터를 전송하지 않습니다. 개인정보와 계좌를 연결하지 않으며 분석 SDK도 없습니다.

## 게임에서 내 주말 계획표로

**게임 속 한 해를 끝까지 마친 삶에서만** 주말 계획표 초안을 열 수 있습니다. 1월1일부터12월31일까지365일(윤년366일)의 완료 기록과 연말 종료 상태를 확인하며, 마지막 날의 진행 중에는 열리지 않습니다. 화면에는 마친 일수와 잠긴 버튼을 보여 줍니다. 완주한 저장 파일을 다시 불러와도 사용할 수 있습니다.

완료 화면의 **주말 계획표 초안 열기**는 기존 주말 회복 플래너로 연결됩니다. 한국 날짜 기준 토·일에는 이번 주말, 평일에는 다가오는 주말을 대상으로 합니다. 완주한 삶과 같은 해면 해당 날짜의 실제 활동 기록을 옮기고, 다른 해면 완주한 해의 토요일·일요일 기록을 각각 평균내어 참고합니다. 출처와 표본 기간을 초안에 표시하며 실제 반복 기록은 그대로 유지합니다.

초안은 같은 브라우저 탭의 임시 저장 공간으로 전달됩니다. 완주한 삶의 날짜·지표·돈·난수는 바뀌지 않습니다. 예전의 미완주 초안은 불러오지 않으며, 시즌2에서 한 해를 완료한 뒤 새로 열어야 합니다. 옮긴 뒤에는 플래너에서 활동의 시간과 이동을 수정할 수 있습니다. 원래 활동명은 유지하고 기존 플래너의 가장 가까운 활동 범주에 대응시키므로, 플래너 지수는 시즌2의 건강·행복 점수와 다릅니다.

초안을 표시하는 기존 플래너에서 기본 활동12개와 시즌2 활동50개를 검색하고 추가할 수 있습니다. 초안으로 진입하면 시즌2 목록이 먼저 열립니다. 수동 활동은 원래 경험 기록과 구분되며, 길이·이동·심리 소모도 편집과 복제·삭제·계획 기억을 지원합니다. 기본 길이는 활동·준비·집/근거리/수업·근무 장소별 이동0/30/60분을 합쳐30분 단위로 올립니다. 육아 연령과 미용 주기를 함께 표시하고, 실제 육아 기록은 기본 돌봄과 겹친 시간만 제외합니다. 게임의 비용·보상·역할 제한은 적용하지 않습니다.

## 자료와 한계

새 인생은 17시도 인구와 가구 월수입의 공개 분포를 참고합니다. 소득은 2024 주거실태조사(2023년 가구 실수령 경상소득)에서 가구원수 비중에 지역·연령 주변분포를 결합하고, 미성년 자녀를 둔 한부모는 2024 한부모가족 실태조사 비중을 사용합니다. 실제 지역×연령×가구형태 공동분포가 없으므로 합성 확률이며 한국인을 대표하는 표본이 아닙니다. 구간 안의 균등 추첨과 지역 조정 전 최상위 월1,200만원 상한도 게임 가정입니다. 원표와 조정 전 추첨액을 보존합니다. 서울·경기의 구·시군별 근로소득 평균 격차를 가구수입에 연결하므로 조정 후에는 이 금액을 넘을 수 있습니다. [상세 출처·방식](weekend_season2_doc.html#life-sources)을 확인할 수 있습니다.

직장인 개인 수입 하한190만원, 대학원생 개인 연구·장학지원80~220만원은 별도 게임 가정입니다. 2026 최저임금의 세후 환산값이나 보편 장학금 지급액이라고 주장하지 않습니다. 가족 분담은 배우자와 복무 중이 아닌 성인 자녀에게만 배정하며 배우자400만원·성인 자녀당150만원·합계650만원 상한을 둡니다. 기본생활비는 2026 생계급여 선정기준을 비주거 참고 하한으로 사용하고, 주거비·개인 활동 예산 최소15만원·여유 최소10만원이 부족하면 가상 생활안정지원으로 부족분만 채웁니다. 실제 복지 수급 자격이나 지급액은 계산하지 않습니다. 개인 활동 예산은 수입으로 더하지 않습니다.

자동 배정 상태에서는 나이·지역·역할·가족·주거를 바꾸면 살림도 함께 맞춥니다. 직접 금액을 바꾸면 이후 조건 변경으로 덮어쓰지 않으며 **이 조건에 맞춰 살림 다시 정하기**에서 명시적으로 다시 배정할 수 있습니다. 이전 저장에는 새 모델을 적용하지 않습니다. 시작 현금·가족 분담·지출 비율·비상 여유는 게임 가정이며 미래 연도도 자료 시점의 금액을 사용합니다.

공휴일의 날짜·출처·확인일은 `calendar.js`의 `holidaySources`에 있습니다. 2025년 최초 발표 이후의 2026년 노동절·제헌절 변경도 공식 자료로 확인했습니다. 지역별 공휴일이나 직장별 근무일은 반영하지 않습니다.

남·여 커트는 한국소비자원 참가격의 2026년 9월 16개 지역 조사값을 사용합니다. 세종은 같은 달 자료가 확인되지 않아 게임 기본값을 표시합니다. 부산 펌·염색 한 업체와 서울·부산 저녁 강좌 사례는 지역 평균이 아닙니다. 강좌는 전체 수강료·재료비·선택 대여료를 표시하고 회당 환산합니다. 미확인 활동에는 임의 지역 배율을 적용하지 않습니다. 자료 시점의 비용을 모든 게임 날짜에 고정 적용하며 실제 예약·수업 종류·운영 요일·선결제 조건은 재현하지 않습니다. [가격 출처와 범위](weekend_season2_doc.html#activity-prices)를 확인할 수 있습니다.

그 밖의 비용·이동시간·피로·기분·성과·사건 확률은 게임용 가정입니다. 프리셋은 현실 인구집단의 평균이 아닙니다. 성별로 능력·수입·돌봄을 배정하지 않으며, 주거 유형 자체로 행복 순위를 매기지 않습니다. 같은 선호·피로·경제·마감 맥락에서 선택의 결과를 읽도록 구성했습니다.

가족 생성은 혼인 연령 통계를 추정하지 않습니다. 너무 작은 나이 차가 흔히 생성되던 문제를 줄이기 위해 새 자동 인생에만 부모·자녀 나이 차25세 이상과 첫 자녀와28~35세 차 중심의 가중치를 적용합니다. 결혼 시점 자체는 기록하지 않으며, 수동으로 정한 나이와 기존 저장의 가족은 바꾸지 않습니다. 피부색은 밝은 베이지부터 조금 짙은 따뜻한 톤까지 가까운 4단계로 표현합니다. 기존 저장의 팔레트 식별자는 유지하고 그림 색상만 바뀝니다. 자녀 피부색은 주인공의 삽화 팔레트와 연결하고 성인 자녀는 성인에 가까운 크기로 그립니다. 0~1세는 바닥을 기어가는 자세와 작은 움직임으로 표현하며, 움직임 줄이기에서는 같은 자세로 멈춥니다. 이는 유전이나 가족 형태를 판단하는 규칙이 아닌 그림의 일관성을 위한 표현입니다.

주거비는 한국도시연구소의 2026년1~7월 국토교통부 실거래 분석을 참고합니다. 17시도 전체주택·아파트 면적단가에 가구 규모에 맞는 면적을 적용합니다. 월세 원표는 보증금÷월세26.7배 이하 계약의 평균이며 전체 임대가구 평균이 아닙니다. 호갱노노의 서울 소형주택과 구미 가족형 아파트 계약 사례도 보증금·면적·계약일을 짝지어 확인했습니다. 개별 사례를 지역 평균으로 사용하지 않습니다.

월세는 게임 하한30만원과10만원 단위를 적용하고, 월세+정밀 이자+관리·유지비 합계도10만원 단위로 맞춥니다. 관리·유지비에는 이 반올림 잔차가 포함됩니다. 면적·주택상태·계약·대출비율·금리·관리비·공동주거65%분담은 합성 가정입니다. 자가와 전세는 월세가0이어도 이자·관리비가 나갑니다. 집값·보증금은 시작 당시 자산 조건이며 거래·반환·원금 상환·변동금리·연체이자는 구현하지 않습니다. 대출은 시작 현금에 더하지 않고 연말 채무에 남깁니다. 월 주거비는 부과 시 소비로 한 번 기록하고 미납 후 납부할 때 다시 더하지 않습니다. 연말 주거비는 실제 장부 합계이며 미납도 포함합니다.

질병관리청 자료는 질병 이름과 진료 후 쉬며 생활을 조정하는 배경에 사용했습니다. 질병 사건의 빈도, 7일·14일 뒤 돌아보는 시점, 지표 변화는 게임 가정이며 실제 감염·회복을 예측하지 않습니다. 수족구의 만 2세 이하 제한은 요청된 게임 범위로, 현실의 발병 연령 상한이 아닙니다. 의료비 자료를 확보하지 않았으므로 진료비를 추정해 부과하지 않습니다. 실제 병력은 수집하지 않습니다. 군복무 중인 아들은 별도 가상 조건으로 생성·수정하며, 모든 남자 자녀가 복무한다고 가정하지 않습니다.

참고한 [80억 분의 1](https://1in8b.life/ko/)에서는 선택 누적과 회고 구조만 참고했습니다. 문구·이미지·사건을 복제하지 않았습니다. 첨부된 2026-10-16 설계안 v0.1과 사용자 구현 요청을 범위 기준으로 삼았습니다.

다년 이어하기, 실제 금융·의료·취업 예측, 개별 지인별 장편 서사, 여행·장기 프로젝트는 후속 범위입니다. 이동은 지역 유형과 수단에 따른 근사입니다. 30~45분 플레이 시간이나 재미, 저사양 성능은 검증했다고 주장하지 않습니다.

이름은 김종미·고우리(2022)의 출생신고 이름 연구 부록 표5를 사용합니다. 1940년대부터 2020~2021년까지 9개 기간의 성별 상위20개 이름(시대 간 중복 포함360항목)을 원표와 대조했습니다. 시즌 연도−나이로 출생 코호트를 정하고 목록 안에서 균등 추첨합니다. 전체 신고 건수·분모가 없는 순위 목록이므로 실제 빈도나 현재 성인 전체의 분포를 주장하지 않습니다. 자료 범위 밖 출생연도는 가까운 확인 코호트로 대체하고 미래 유행을 추측하지 않습니다. 기존 저장의 이름은 바꾸지 않습니다.

새 삶의 연령별 건강은 의학적 관측치가 아닌 게임 기본값입니다. 양의 건강 변화·음의 피로 변화와 일상 회복량에 연령별 회복 비율을 한 번 적용하며, 하루 건강 기준은 시작 건강−2입니다. 피해량·업무 피로 증가·질병 후속 날짜에는 연령 배율을 적용하지 않습니다. 같은 나이라도 생활 선택에 따라 상태가 달라지며 모든 연령의 상한은100으로 같습니다. 선택적 v6 설정 ageHealthModel이 없거나 null인 기존 저장은 시작 기준70·회복100%와 현재 수치를 그대로 유지합니다. WHO 자료는 개인차가 크다는 배경 설명이며 게임 숫자의 출처가 아닙니다. [적용값과 한계](weekend_season2_doc.html#age-health-sources)를 확인할 수 있습니다.
